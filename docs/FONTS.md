# Bundled fonts

The application bundles four variable TrueType font files under `app/src/assets/fonts/`:

| Family | Bundled files | Embedded version | License |
| --- | --- | --- | --- |
| Bodoni Moda | Regular and italic | 2.005 | SIL Open Font License 1.1 |
| JetBrains Mono | Regular and italic | 2.211 | SIL Open Font License 1.1 |

The font name and copyright records were inspected directly in the bundled TTF files. They identify the Bodoni Moda Project Authors and JetBrains Mono Project Authors respectively. The matching upstream license texts are included alongside this project under `third_party/fonts/`.

- **Bodoni Moda:** Copyright 2020 The Bodoni Moda Project Authors. Upstream: [indestructible-type/Bodoni](https://github.com/indestructible-type/Bodoni); authoritative Google Fonts license copy: [OFL.txt](https://github.com/google/fonts/blob/main/ofl/bodonimoda/OFL.txt). Upstream metadata identifies version 2.005 and the two variable font files.
- **JetBrains Mono:** Copyright 2020 The JetBrains Mono Project Authors. Upstream: [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono); license: [OFL.txt](https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt). The embedded font records identify version 2.211.

The SIL Open Font License permits redistribution of the font software with software when its conditions are met. Each font remains under its own license; the repository's MIT license applies to Glyph project code and does not replace the font licenses.
